Cần có Violentmonkey (Kiwi Browser / Chrome) trước khi bấm Cài đặt.

Cài trong 3 bước

  1. Cài Violentmonkey (Kiwi Browser trên Android, hoặc Chrome Web Store trên PC).
  2. Bấm CÀI ĐẶT ở trên, Violentmonkey hiện màn hình xác nhận, chọn Confirm installation.
  3. Mở gtraffic.io, bảng ♛ BYPASS KING hiện góc dưới-phải. Có bản mới trên GitHub thì script tự cập nhật.

Giao diện

3 chế độ: Đầy đủ · Compact · biểu tượng nổi ♛ (chạm để mở, kéo để di chuyển).

Làm gì, không làm gì

  • Đọc nhiệm vụ trên trang kèm độ tin cậy
  • OCR ảnh do bạn chọn (chỉ gợi ý)
  • Liệt kê mã đang hiển thị, COPY CODE
  • Đồng hồ Start/Pause/Resume, lịch sử 200 link
  • Không giải CAPTCHA
  • Không click quảng cáo, không tạo lượt giả
  • Không tự gửi yêu cầu khi hết giờ
  • Không đọc cookie, token, tài khoản
